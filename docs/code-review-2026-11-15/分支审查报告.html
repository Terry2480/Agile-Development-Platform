三、代码层面的小问题

  1. lint 未通过：上述 2 个 any 错误 + 2 个未使用变量警告，建议合并前修掉。
  2. 没有 test script：package.json 未定义测试命令，README 也未说明如何跑测试（实际需要 node --import tsx --test tests/...）；且 docs/dm-and-docs.md 中给出的 node --test tests/xxx.test.ts 命令直接执行会因缺少 tsx loader 而报错，文档命令有误。

该分支将登录页重写为 tab 切换式（登录/注册），不再有"飞书登录"按钮——而当前本机运行的版本（localhost:3000 截图）是有该入口的。若合入此分支，第三方登录入口将丢失，从交互设计角度属于功能性退化。合并前需确认团队以哪条分支的登录方案为准。
