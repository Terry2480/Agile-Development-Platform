## 2. 本次提供的功能

| 功能 | 本次行为与边界 |
| --- | --- |
| 项目空间与团队公共区 | 一个项目一个独立空间；同团队项目不混放。公共区服务跨项目共享，不自动汇总项目内容。项目默认分区：项目文档、协作记录、交付成果；公共区：团队规范、共享参考、公共素材。可调整目录，至少保留一个分区。 |
| 目录和列表 | 多层文件夹；在线文档、上传文件、外部链接统一列表；标题搜索当前整个空间、文件夹优先、名称/更新时间排序、分页、定位实际目录。根层仅建分区。 |
| 在线正文 | 默认阅读、显式编辑；标题、段落、标题块、列表、粗体/斜体、代码块、HTTP(S) 链接、可编辑表格及加行/列。编辑工具是块级基础编辑，不承诺 Word 全量排版或任意 HTML 保真粘贴。 |
| 保存和并发 | 停顿 2 秒自动保存；持续输入最多 15 秒发起一次保存，网络处理时间另计；请求串行。每 20 秒续锁，约 2 分钟无成功续期失效。同账号另一标签页也不能抢锁。服务端成功后才显示已保存。 |
| 本机草稿 | 按账号与文档分开保存；断网保留、重连重试；刷新后可比较服务器与本机草稿、使用草稿、复制文字、丢弃；显式退出登录清除。草稿不等于服务器已保存内容。 |
| 历史版本 | 编辑开始保护、变化时的 10 分钟检查点、手动保存、恢复前保护；相同正文不重复，最多 10 份附加快照。只恢复正文，标题、目录、关联保持。 |
| 正文图片 | 本机选择、粘贴、拖入 JPG/PNG/WebP，每张不超过 10MiB；可引用本项目或同团队公共区已有图片。内部图片不自动生成目录文件条目；正文、历史与副本按资源引用共用，读取重新鉴权。 |
| 文件上传、预览、下载 | 普通文件非空且不超过 100MiB；同名不覆盖。图片、PDF、浏览器支持编码的 MP4/WebM 可预览；Office/压缩包等提供下载。魔数识别，伪装的 HTML/SVG 等按下载处理。支持鉴权 HEAD 和单区间 Range。 |
| 文件替换 | 当前团队成员均可替换；先列出关联影响并确认，校验资料/资源版本。保留资料 ID、标题、路径和关联，原子切换到新资源；副本继续使用旧资源。无可恢复的旧二进制历史；记录当前上传者、时间及操作日志，原上传归因保留。 |
| 外部链接修改 | 团队成员可修改标题与 HTTP(S) 网址；提示关联影响、确认及版本校验；保留资料身份与关联，记录修改人和时间。平台不代替外站登录，也不承诺外站永久可用。 |
| 任务与里程碑关联 | 多选关联本项目或同团队公共资料；批量校验失败不部分写入。入口始终读取原资料最新内容；解除关联保留资料。从任务/里程碑“上传并关联”先选本项目目录，上传与关联一次提交。 |
| 移动、复制 | 同团队内移动保留 ID、正文、历史、文件；跨空间须先解除全部关联，跨团队禁止。复制产生独立条目与正文，共享不可变文件/图片；不复制历史、关联、回收站内容。 |
| 回收站 | 每空间独立，保留 30 天；显示原路径、删除人、删除与到期时间，可阅读未到期内容、恢复整批文件夹或单个子项。原目录不可用时进入“恢复的资料”；重名追加恢复序号。永久删除限负责人/管理员，到期内容不可阅读或恢复。 |
| 模板 | 9 个简明提纲及空白：项目计划、会议纪要、周记录、阶段回顾、交付报告、需求文档、技术设计、API 文档、测试报告。通用课程/软件开发推荐仅影响顺序，不自动创建文档，不改已有内容。 |
| 导出 | 当前已保存内容快照；单篇 PDF，Markdown 含图片 ZIP，目录 ZIP 保持结构和空目录、上传文件、链接清单。最多 500 份非文件夹资料、实际未压缩输出 500MiB；不含历史、回收站、草稿。后台任务可查，仅任务发起者可下载且复查当前来源权限；24 小时有效，部分失败列清单，重试原快照不延长期限。 |
| 生命周期与兼容 | 归档项目文档只读，可复制到可写位置及导出；项目删除将正常资料和回收站转存公共区“原项目名＋日期”，保留身份及到期时间。团队解散限负责人、先处理全部项目、确认永久删除公共资料并取消导出。旧附件 URL 映射到新条目，转存后仍按新位置鉴权。 |
| 后台清理 | 回收站到期、孤立资源、过期导出由运行中的 Node 服务调度；实体删除前检查正文/历史/副本/导出等所有引用。共享资源不会因一个条目删除而消失。删除成功表示逻辑完成，磁盘清理由队列重试。 |

MiB 按 `1024 × 1024` 字节计算；界面简写 MB。正文 JSON 上限 5MiB。团队总配额、本批移动端新增适配不在已确认交付范围。

## 3. 准备环境（启动者执行一次）

前提：完整验收分支、Node.js（开发侧使用 24.18.0）、npm、本机 PostgreSQL；数据库账号能建测试数据库。PDF 导出需可启动的 Edge/Chromium 和中文字体。Windows 默认尝试已安装 Edge；其他路径设置 `DOCUMENT_BROWSER_PATH`。不要把验收账号用于线上环境。

在仓库根目录执行：

```powershell
npm ci
# .env.local 中配置本机 PostgreSQL DATABASE_URL，使用自己的用户名/密码。
# 示例形状：postgresql://用户名:密码@127.0.0.1:5432/普通开发库名
npm run setup:documents
npm run dev:documents
```

打开 **http://127.0.0.1:3112**。停止服务使用启动终端的 Ctrl+C。首次编译稍慢；重新准备是增量操作，不清空现有数据、不重置已有账号密码。准备失败时停止并把错误码交维护者，不执行 `db:push`、seed 覆盖或删除数据库来“修复”。

| 项目 | 审查环境固定值 |
| --- | --- |
| 数据库 | `agilecampus_test_documents_api_20261112` |
| 文件根目录 | 仓库内 `uploads-document-review` |
| 页面端口 | 3112，限本机回环监听 |
| 构建目录 | 审查版独立 Next 缓存；浏览器脚本另用 `.next-document-check` |
| 与普通开发的区别 | 脚本重写子进程数据库名、上传目录与允许 Origin；不改 `.env.local`，不升级普通开发/生产库。`document` 是审查环境的命名，不是浏览器自动提供的隔离能力。 |

不要仅把地址改成另一个端口就认定数据库隔离。跨账号测试用**不同浏览器配置文件或两种浏览器**；同一浏览器同主机的不同端口仍可能共享登录 cookie。锁竞争的同账号标签页测试则故意使用同一登录会话。

此服务默认只在启动者本机可访问。其他组员可各自启动本地审查环境；若集中验收，由维护者另行配置可访问地址、数据库和准确的 `AUTH_ALLOWED_ORIGINS`，不可直接关闭来源校验。页面提示“不允许来自该网站的操作请求”时，先核对协议、主机名、端口与启动脚本。
