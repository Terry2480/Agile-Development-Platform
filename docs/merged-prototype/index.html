最后编辑：林晓彤 · 2 小时前　|　版本 v7　|　3 条评论

1. 项目背景

敏捷校园是一款面向大学生课程项目的敏捷协作工具，支持团队分工、任务看板、即时沟通、教学周里程碑与汇报摘要。

2. 用户角色

整合后支持三级角色：管理员 / 教师 / 学生；团队内另有负责人、组员分工标签。教师可跨组查看进度，学生聚焦"我该做什么"。

3. 核心功能

任务看板与迭代、飞书式私聊与群聊、协作文档与版本、AI 日报与日历、AI 项目助手、Agent 写入 API、时间线甘特、资源占用登记。

Agent 写入 API student 线

外部程序（如 Claude Code）携带本人 Token，即可按本人权限写入任务、完成状态与资源占用。

# 添加任务
curl -X POST /api/agent/tasks \
-H "Authorization: Bearer $TOKEN" \
-d '{"projectId":12,"title":"联调接口"}'

# 填写完成情况
curl -X POST /api/agent/tasks/complete \
-H "Authorization: Bearer $TOKEN" \
-d '{"taskId":31,"done":true}'

# 登记资源占用
curl -X POST /api/agent/resource-usage \
-H "Authorization: Bearer $TOKEN" \
-d '{"resource":"GPU-1","hours":2}'
权限边界：Token 权限 = 持有人权限；管理员可全写，教师只读跨组，学生仅写自己参与的项目。所有写入留痕到活动记录。
