## 方法论依据

严格参照课件要求：

- **PERSONA 七要素**：Primary（基于真实访谈）、Empathy、Realistic、Singular、Objectives、Number、Applicable
- **建模过程循环**：拼凑 → 组织 → 细节 → 求精，循环反复
- **互动人物角色 v1.6** 维度：可视化瞬间、情绪状态、环境、意志力与认知负荷、注意力、接触点、包容性
- **避免三类设计陷阱**：弹性用户、自参考设计、边缘情况设计（用「A 会经常做这种操作吗？」判断）
- **角色定义**：角色是用户在系统中的公共需求与行为模式，一人可扮演多个角色

## 重要声明

**这三份 Persona 目前是基于项目功能与校园场景推导的初版假设，尚未经过真实用户访谈或问卷验证。** 课件明确指出 Persona 应基于调研与问卷获得的真实数据，而不是头脑风暴。因此：

- 汇报时应明确标注为「初版假设」，不可作为已验证的用户研究结论；
- 演示文稿第 11 页给出了验证计划：访谈 6 人（覆盖 2 个小组）、问卷 30 份、观察一次真实小组周会，之后据此修订三个人物。
