# Persona 演示文稿源文件说明

本目录补充 `敏捷校园_Persona用户建模_Step-5-Preview.pptx` 的可编辑源文件与预览图，便于后续修改与复用。

## 内容

- `slides/01.slide` ~ `12.slide`：12 页的 slidep DSL 源文件（纯组件标签语法，每页一个文件）。
- `preview/`：6 张关键页渲染截图（封面 / 角色关系图 / 人物档案 / 场景页 / 边界页 / 结尾页），用于快速核对视觉效果。

## 重建方式

在有 slidep CLI 的环境里，从本目录根目录执行：

```bash
slidep create "敏捷校园_Persona用户建模_Step-5-Preview.pptx"
for n in 01 02 03 04 05 06 07 08 09 10 11 12; do
  slidep upsert-dsl "敏捷校园_Persona用户建模_Step-5-Preview.pptx" --dsl-file "docs/persona-2026-11-15/slides/$n.slide"
done
```

`upsert-dsl` 默认追加到末尾，因此必须按 01→12 顺序一次性写入；若需替换指定页用 `--page-index <从0开始>`。版式与配色约定见同目录 `DESIGN.md`。
