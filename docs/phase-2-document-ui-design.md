# 文档系统桌面页面与交互方案

状态：已确认的桌面方案汇总，依据 Q1—59（Q56 暂缓）。本批隔离版已实现并完成开发检查，人工验收未签收；当前行为及限制见 [验收指南](document-system-acceptance.md)，实际验证见 [交付记录](document-delivery-progress.md)，数据/API 由技术设计维护。

## 1. 入口与信息架构

| 入口 | 到达位置 | 上下文 |
| --- | --- | --- |
| 顶部项目文档 | 当前项目文档空间 | 与项目任务、团队聊天、项目概览同级 |
| 左侧主导航团队资料 | 选择团队后进入公共区 | 面向普通成员，不藏在团队管理内 |
| 项目概览文档快捷入口 | 本项目文档空间 | 替代旧文件管理区，不保留第二套独立管理界面 |
| 项目文档的团队资料快捷入口 | 所属团队公共区 | 明确显示空间变化 |
| 任务/里程碑关联资料 | 对应资料阅读或预览 | 不复制内容，访问仍按当前权限 |

空间内固定入口：目录、回收站、导出任务。切换空间不混合搜索结果或目录状态；团队选择须明显，避免误上传。

## 2. 桌面主布局

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶部导航：项目任务 / 团队聊天 / 项目概览 / 项目文档            │
├─────────┬─────────────┬───────────────────────────────────────┤
│ 现有主  │ 文档目录    │ 空间名称、面包屑、空间内标题搜索       │
│ 导航及  │ 分区/文件夹 │                                       │
│ 项目入口│             │ 文件夹：资料列表 + 新建 / 上传         │
│         │             │ 文档：阅读或编辑 + 保存状态/操作       │
│         │             │ 文件：预览或下载                      │
│         │ 回收站      │                                       │
│         │ 导出任务    │ 按需打开资料信息，不常驻项目活动侧栏   │
└─────────┴─────────────┴───────────────────────────────────────┘
```

这是区域关系示意，尺寸/间距/字体沿用现有主题后通过实际线框确定，不额外新增视觉体系。目录树可收起，返回目录恢复位置；本轮不设计移动端抽屉布局，不移除现有适配。

## 3. 目录与列表

- 根层只显示分区并提供新建分区；进入分区/文件夹后提供新建和上传。
- 新建菜单：在线文档、文件夹、外部链接。在线文档选择空白或系统模板并填写名称，明确目标目录。
- 上传按钮及拖入列表区域都生成独立文件资料，不等同编辑器插图。任务入口上传须先选本项目目录，再自动关联任务。
- 单一列表展示名称/类型、最近修改人、更新时间及更多操作。文件夹优先，支持名称/更新时间排序。无需卡片和网格视图。
- 当前空间标题搜索跨其全部目录，结果附路径及定位入口；回收站单独搜索，不混入其他空间或正文搜索。与任务搜索分开。
- 同名、被引用、正在编辑或只读等不可执行原因明确提示；服务端返回冲突后保留用户填写内容，不用成功提示掩盖失败。

## 4. 阅读、编辑及资料信息

打开在线文档默认阅读，不自动抢锁。阅读顶部显示标题、编辑入口、历史和导出等可用操作；有人编辑显示编辑者，正文读取服务器最近已保存内容。

点击编辑取得锁后进入编辑模式，标题与正文一起受保护。显示未保存/保存中/已保存/保存失败，提供立即保存、保存版本、结束编辑。自动保存沿用停输入 2 秒/持续输入最多 15 秒，续期 20 秒/失联 2 分钟，细节不暴露给普通用户。

- 正常结束编辑先保存成功再释放锁，回阅读；失败保留草稿，提示等待保存或保留草稿离开。
- 失锁/失权立即停止后续写入；不自动用草稿覆盖服务器。恢复草稿按既定比较与明确确认流程。
- 插图支持选文件/粘贴/拖入及选择合法已有图片；上传状态与正文保存状态分开，不把本机预览视为上传成功。
- 资料信息按需展开：空间/路径、创建与最近修改人和时间、适用文件属性、任务/里程碑关联及跳转。历史使用独立入口。

## 5. 三个辅助页面/面板

| 页面 | 展示与操作 | 关键保护 |
| --- | --- | --- |
| 历史版本 | 左侧版本时间/作者/原因，右侧正文预览，可切换当前正文 | 恢复仅正文，先持锁并确认，保护当前内容；标题位置关联不回退 |
| 回收站 | 当前空间名称、原路径、删除人、删除/到期时间，浏览子项、恢复 | 到期禁读禁恢复，永久删除仅负责人/管理员且确认；恢复返回实际路径 |
| 导出任务 | 进度、成功/失败项及原因、重试/下载、24 小时有效期 | partial 与 completed 区分，失败清单不隐瞒，权限变化不能下载旧包 |

历史预览和导出不取得编辑锁，恢复历史才需要；回收站未到期资料可按权限预览/下载，继续编辑须先恢复。

## 6. 端到端操作路径

1. 写文档：进入项目文档 → 选择目录 → 新建在线文档 → 选空白/模板并命名 → 打开阅读 → 点击编辑 → 输入/自动保存 → 结束编辑。
2. 交任务成果：任务详情上传 → 选择项目目录 → 上传成功并关联任务；或关联本项目/公共区已有资料，不能重复添加。
3. 更新报告：资料更多操作选择替换 → 显示引用影响并确认 → 上传成功后切换 → 既有任务指向新内容，独立副本不变。
4. 整理资料：选择移动/复制目标 → 检查名称/锁/关联/空间 → 成功显示实际位置；整文件夹失败不留下半套结构。
5. 找回资料：回收站找到条目/子项 → 恢复 → 告知实际路径和重名后的名称；原父级失效则恢复分区。
6. 交付成果：选择文档/目录并选 PDF 或 Markdown → 创建导出任务 → 可继续工作 → 任务面板查看并下载，失败按同快照重试。

## 7. 状态及反馈检查

必须覆盖：无项目/无团队、空目录、无搜索结果、首次加载、加载失败重试、上传中/失败、只读归档、他人编辑、失锁、无权限、正文超限、导出超限/部分失败/过期、回收站到期。

删除目录展示影响范围；存在引用/编辑锁阻止。项目删除展示转存去向及正常/回收数量，团队删除展示永久影响、导出入口及取消导出。确认文字表达用户影响，不暴露表名、CAS 或资源 ID。

## 8. 设计审查与实现入口

目录与列表、阅读与编辑、历史/回收站/导出任务三组桌面线框均获用户认可，可作为实现参考。原型使用内存样例和模拟状态，场景/身份切换器只用于审查，不进入产品。

本轮真实实现与测试结果统一记录在交付验证记录；组员按验收指南核对当前版本。设计认可、开发验证与人工签收分别记录，不相互替代。

## 2026-11-14 公共区及导航审查调整

用户要求公共区不能套用项目的默认分类。新公共空间采用“团队规范、共享参考、公共素材”，项目空间保持其项目分类。公共区标题显示“团队公共资料”和所属团队，目录标题为“公共资料分类”，常驻说明跨项目共享、不自动汇总项目文档。两类空间继续复用目录操作及权限模型。

现有隔离审查团队的三个默认分区通过迁移身份识别后原位更名，保留 ID、文档和引用；用户改名、移动过的分区以及自定义分区不改，遇重名不覆盖。普通/生产库未变更；既有空间的正式升级仍需纳入发布迁移方案。

主导航补齐“项目工作台、通知中心、我的待办”常驻文字和无障碍名称。项目管理负责创建、归档及项目元数据管理；项目工作台进入具体项目的任务、聊天、概览和文档，深层导航差异化后续继续设计。
