## 二、本次修复的 bug

### Bug 1（功能回归，严重）：v6.3 丢失 AI 日报 / 日历 / 任务进度

v6.3 在重做发布会首页时，删除了 `功能/ai-home-dashboard` 分支的整套实现：

- `lib/home-report.ts`、`lib/calendar-events.ts`
- `app/api/home/daily-report/route.ts`、`app/api/home/calendar/route.ts`
- `components/ws/DailyReportCard.tsx`、`components/ws/HomeCalendar.tsx`
- 对应 CSS（globals.css 37 行）与 2 个测试文件

这些正是 PDF 需求里 4.1（首页待办+进度+截止）、4.2（AI 日报）和"日历"计划项。**修复**：从 `terry/ai-dashboard-acceptance`（已修时区版）整体移植回 v6.3，补回 CSS，并把 `TodayPanel` 换成含进度条 + 日报 + 日历挂载的修好版。

### Bug 2（时区错误）：非东八区用户会算错"今天截止"

v6.3 的 `TodayPanel` 用浏览器本地时区（`getFullYear/getMonth/getDate`）生成日期键，而 `dueOn` 和后端日报按东八区（Asia/Hong_Kong / +8h）。系统时区不在 UTC+8 时，会高亮错日历天、误判任务截止。**修复**：统一复用 `lib/api-client` 的 `dayKey(new Date().toISOString())`。

### Bug 3（lint error）：2 个 `catch (error: any)` + 2 个未用变量

`app/api/auth/me/route.ts:41`、`app/api/teams/[id]/labels/route.ts:42` 的 `catch (error: any)`，以及 `tests/task-transactions.test.mjs` 未使用的 `and` 导入与 `taskLabels` 解构。**修复**：改为代码库惯用的 `catch (caught: unknown)` + 结构化断言，清理未用变量。lint 4 problems → 0。

### Bug 4（工程）：没有 `test` 脚本

`package.json` 缺 `test` 脚本，`npm test` 无输出。**修复**：新增 `node --import tsx --test tests/*.test.*`。

## 四、使用方式

```bash
cd Agile-Development-Platform-ai-dashboard
git checkout terry/v63-bugfix
npm ci --include=dev
# 配好 .env.local 的 DATABASE_URL（本地可 docker compose up -d 起 PostgreSQL 16）
npm run db:push          # 首次建表
npm run dev              # 访问 http://localhost:3000
```

进工作台 → 左侧「今日」视图，即可看到：任务进度条、截止临近期、进行中待办、AI 日报卡片（可展开/切换日期）、项目日历（点日期看安排）。
