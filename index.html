关于项目

让高校团队的协作与进度
变得透明、可控、可被 AI 驱动

针对高校实验室与教学团队在项目管理上的协作与进度透明难题，AgileCampus 提供一套轻量的看板协作平台，并引入 AI 项目助手与 Personal API Token，让外部程序（如 Claude Code）也能直接写入任务与资源占用，实现「人机协作」的敏捷管理。

核心功能

一套平台，覆盖团队协作全流程

👥

团队与角色

创建 / 加入团队，admin / teacher / student 三级权限。

🗂️

项目看板

里程碑 + 拖拽看板 + 四维分组与标签筛选。

📊

跨项目总览

聚合所在团队全部项目与任务进度。

🤖

AI 项目助手

对话式拆解任务，草案-确认两段式安全落库。

🖥️

资源占用登记

团队共享资源（服务器 / 算力）占用登记与时长汇总。

📅

时间线甘特

按里程碑分组的甘特视图，逾期标红、今日竖线。
