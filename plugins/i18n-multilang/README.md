# 多语言插件（i18n-multilang）

AgileCampus 标准插件首个官方示例：启用后页面右下角出现 🌐 切换器，
界面文案可切换为 **英语 / 日语 / 法语 / 俄语**，随时切回中文。

- 权限：`ui:translate`（文本替换）、`ui:mount`（切换器）、`storage:local`（记忆语言选择）
- 原理（v1.1 两层翻译，见 `dictionary.ts` 的 `translateText`）：
  1. **整句精确匹配**——界面文案整句收录（约 300 词条 × 四语，单表四列结构）；
  2. **分段翻译**——未整句命中时按「汉字段 / 全角标点 / 数字与拉丁」切分，
     逐段查词典，数字与用户数据原样保留，因此 `2 位成员 · 1 个项目`、
     `待办 1 · 进行中 0`、`11月23日星期一` 这类动态文案也能翻译；
  3. **模板规则**——中文日期（`2026年11月23日星期一` → `2026-11-23 Monday`）、
     量词吞并（`3 个任务` → `3 tasks`）、计数句式（`注意：有 1 个…`）。
- 不翻译：项目名 / 任务标题 / 人名等用户数据、代码块、可编辑正文（contenteditable）、
  输入框取值；输入框的 placeholder 仍翻译。MutationObserver 跟踪 SPA 局部刷新；
  停用或切回中文时完整还原全部原文。
- 测试：宿主仓库 `tests/i18n-dictionary.test.ts`（四语键集一致 / 行表唯一 /
  无空值 / 分段与日期规则用例）。

文件：`plugin.ts`（插件主体）· `dictionary.ts`（四语词典与翻译管线）。
完整标准格式见上级目录 [PLUGIN-SPEC.md](../../docs/PLUGIN-SPEC.md)。
